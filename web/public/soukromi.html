Soukromí a podpora

Závody aut: kalendář automobilových závodů v Česku. Platí pro web www.zavody-aut.cz a aplikaci Závody aut pro iPhone, iPad a Mac. Platné od 6. 11. 2026.

Jaké údaje zpracováváme

Žádné osobní údaje o vás nesbíráme. Aplikace nemá uživatelské účty, přihlášení ani reklamy a nesleduje vás napříč aplikacemi a weby.

  • Oblíbené závody, filtry a domovský kraj zůstávají jen ve vašem zařízení. Na server se neposílají.
  • Poloha (jen když zapnete „Nejblíž mně“ nebo ukážete polohu na mapě) se použije v zařízení k výpočtu vzdálenosti a nikam se neodesílá.
  • Uložené závody pro offline (detail, mapa okolí, dokumenty pořadatele) se ukládají jen do zařízení a po závodě se smažou.
  • Kalendář: závod přidáte přes systémový formulář. Aplikace do vašeho kalendáře nevidí.

Služby třetích stran

Aplikace stahuje data přímo z těchto služeb. Jako každý server vidí IP adresu zařízení, nic dalšího jim neposíláme:

  • www.zavody-aut.cz (Cloudflare): kalendář závodů,
  • OpenFreeMap: mapové podklady (data © přispěvatelé OpenStreetMap),
  • Open-Meteo: předpověď počasí v místě závodu (souřadnice obce, ne vaše poloha),
  • RainViewer: dešťový radar.

Web navíc měří návštěvnost přes Cloudflare Web Analytics (bez cookies, bez osobních údajů). Aplikace analytiku nemá.

Data o závodech

Údaje o závodech pocházejí z veřejných kalendářů a webů pořadatelů. U každého závodu je odkaz na zdroj. Osobní údaje jezdců neukládáme, výsledky nestahujeme.
